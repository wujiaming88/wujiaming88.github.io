## 本周一句话

> **这是"旗舰发布超级周"叠加"具身资本化狂飙周"。** OpenAI（GPT-5.6 家族 + Codex 并入 ChatGPT）、Meta（首个付费模型 Muse Spark 1.1）、SpaceXAI（"Opus 级"Grok 4.5）三大旗舰在 7/8–7/9 隔天连发，全行业从"聊天助手"集体转向"**企业级 Agentic 工作台**"，**价格战与 token 效率**成为核心武器；同时中国具身赛道以宇树 IPO 注册生效、优必选 U1 首发订单破 1.3 万台掀起资本高潮，腾讯混元 Hy3 开源 + 元宝 Agent 全免费高调重返第一梯队。**焦点已从"谁更聪明"转向"谁更便宜、谁更能干活、谁分发得更广"。**

## 🔥 本周 TOP 5

### 1. OpenAI：GPT-5.6 家族 + Codex 并入 ChatGPT ｜ 7-09

7 月 9 日 OpenAI 一次性宣布三件事：旗舰编程工具 **Codex 正式并入 ChatGPT 桌面端 App**，把 ChatGPT 改造成面向工程师的"一站式工作台"；推出企业/专业场景的 **ChatGPT "Work" 模式**；发布 **GPT-5.6 模型家族**，旗舰推理模型 **GPT-5.6 Sol** 于 7/9 起向付费计划灰度推送。ChatGPT 已近 10 亿用户、Codex 约 500 万周活，OpenAI 用巨大用户基座碾压式分发 Codex 能力，直接对标 Anthropic Claude Code 与微软 M365 Copilot。

↳ **为什么重要**：这是本季度最大产品战略转向——从消费级聊天走向企业级 Agent 工作台；叠加 IPO 保密文件信号，OpenAI 进入商业化决胜期。

来源：[OpenAI Model Release Notes](https://help.openai.com/en/articles/9624314-model-release-notes) · [Business Insider](https://www.businessinsider.com/openai-codex-chatgpt-app-releases-gpt-5-6-models-2026-7)

### 2. Meta：首个付费模型 Muse Spark 1.1 ｜ 7-09

Meta 基座品牌从 Llama 转向 **Muse** 系（Alexandr Wang 领导的 Superintelligence Labs 主导）。7/9 发布 **Muse Spark 1.1**——Meta **首个付费商用模型**，定价 **$1.25/百万输入、$4.25/百万输出**，主攻 agentic coding。扎克伯格为此**时隔三年首次在 X 发帖**，称其"在 Agent 性能、工具使用、计算机操作上最强"。7/7 还发布图像模型 Muse Image。

↳ **为什么重要**：Meta 放弃"纯开源免费"路线转向付费闭源商用，直插最热的 agentic coding 主战场；扎克伯格三年首发 X 凸显重视程度。

来源：[TechCrunch](https://techcrunch.com/2026/07/09/meta-enters-the-crowded-ai-coding-battle-with-muse-spark-1-1/) · [CNBC](https://www.cnbc.com/2026/07/09/meta-jumps-into-ai-coding-market-to-chase-anthropic-and-openai.html)

### 3. SpaceXAI：Grok 4.5，Opus 级能力半价入场 ｜ 7-08

xAI（现更名/并入 **SpaceXAI**，上市后首个新模型）发布 **Grok 4.5**，定位"全能工作马"，核心卖点是 **token 效率约为领先模型的 2 倍**，定价 **$2/百万输入、$6/百万输出**（对比 Opus 4.7 的 $5/$25）。Musk 称其"Opus 级、内部评估约等于 Opus 4.7，但快得多、成本更低"。

↳ **为什么重要**：本周三大旗舰中价格最激进者，以"顶级能力 + 极致性价比"直插高端性价比空档，可能加速全行业价格战与 token 成本下探。

来源：[TechCrunch](https://techcrunch.com/2026/07/08/spacexai-releases-grok-4-5-which-elon-describes-as-an-opus-class-model/)

### 4. 宇树科技：IPO 注册生效，将成"具身第一股" ｜ 7-06

7/6 上交所显示宇树科技科创板 IPO 审核状态变更为"注册生效"（7/2 证监会批复）。从 3/20 提交到注册生效仅 **104 天**。招股书披露拟发行不低于 4044.64 万股、募资总额 **42.02 亿元**、估值约 **420 亿元**。人形机器人单价已从 2023 年 59.34 万元降至 2025 年 16.64 万元。

↳ **为什么重要**：全球首家冲刺公开上市的纯人形/足式机器人本体厂商，104 天极速过会体现政策强支持；上市后融资能力将放大其在"量产元年"的产能与价格战承受力。

来源：[央广网](https://finance.cnr.cn/jdt/20260706/t20260706_527694090.shtml) · [21世纪经济报道](https://www.xincai.com/article/nifxpik8414140)

### 5. 腾讯：混元 Hy3 开源 + 元宝 Agent 全免费 ｜ 7-06

7/6 腾讯正式发布基座模型 **混元 Hy3 并开源**，元宝同步接入并**免费上线 Agent 能力**。腾讯称 Hy3 取得"比肩参数量大 2~5 倍旗舰模型"的效果；在 **270 位专家真实工作盲测中 Hy3 均分 2.67/4，优于 GLM5.1 的 2.51/4**。这是姚顺雨接管腾讯大模型研发后的首个正式旗舰。发布当日腾讯港股涨 4.82%、市值 4.11 万亿港元。

↳ **为什么重要**："实用性优先 + 小参数比肩大模型 + 元宝全免费 + 盲测胜 GLM5.1"，标志腾讯正式重返中国大模型第一梯队。

来源：[财新](https://companies.caixin.com/m/2026-07-06/102461428.html) · [IT之家/新浪](https://finance.sina.com.cn/tech/digi/2026-07-06/doc-inifwfpy8614200.shtml)

## 🧭 三条主线趋势

**一 · 全行业从"聊天助手"集体转向"企业级 Agentic 工作台"。** OpenAI 把 Codex 并入 ChatGPT + Work 模式、Meta 首个付费模型主打 agentic coding、微软 Copilot 承接 GPT-5.6、Cursor 上线 Auto-review 治理 agent 自主性、Claude Code 加桌面内置浏览器——编程/办公自动化已成决胜场，各家把"浏览器/沙箱/远程执行 + 更强审批护栏"做成标配。

**二 · 价格战与 token 效率成核心武器，中国开源模型成全球 agent 生态成本基础层。** Grok 4.5 打"Opus 能力/半价/2 倍 token 效率"、GPT-5.6 分 Sol/Terra/Luna 高低配、Meta $1.25 低价入场、DeepSeek 分时定价 + V4 正式版逼近前沿；更关键的是 Perplexity 直接把智谱 GLM 5.2 后训练成 agent 编排器（0.344x Opus 成本），坐实中国开源模型"被集成/被对标"的全球地位。

**三 · 具身机器人（中国）资本化狂飙 + 云厂"绑定顶级模型"对垒。** 宇树 IPO 注册生效（约 420 亿元）+ 优必选 U1 首发 1.3 万台订单，中国具身从"技术演示"迈向"资本 + 量产"双轮；云侧 AWS 上线 Claude Sonnet 5 + 自研 Graviton5 降推理成本，Azure 几乎同步把 GPT-5.6 全线接入 M365 + Foundry；NVIDIA 无硬件发布但以 ICML 2026 开放模型生态（Cosmos 3 全模态）锁定学术底座。

### OpenAI（GPT-5/ChatGPT/Codex）
- 本周动态：本周OpenAI打出"办公超级App"这张大牌。**2026年7月9日（周四）**，OpenAI在直播中一次性宣布三件事：①将旗舰编程工具 **Codex 正式并入 ChatGPT 桌面端App**，把ChatGPT改造成面向工程师和专业人士的"一站式工作台"；②推出面向企业/专业场景的 **ChatGPT "Work" 设置（工作模式）**；③发布全新的 **GPT-5.6 模型家族**，其中旗舰推理模型为 **GPT-5.6 Sol**，定位"跨编程、研究、科学、网络安全、计算机操作和设计的复杂工作"。据OpenAI官方帮助中心（Model Release Notes）确认，GPT-5.6 Sol 于7月9日开始向"符合条件的付费ChatGPT计划"灰度推送，Free/Go/未登录用户暂不包含，其余GPT-5.6家族模型（推测含Terra、Luna等分层）按产品与套餐差异化开放。新的 Work 桌面工作台继承了Codex的核心能力：可修改本地文件、可在浏览器中自主操作（agentic）。Codex负责人Andrew Ambrosino称此次合并"只是第一步"，目标是统一web/mobile/desktop体验但"要做得深思熟虑，而非简单加个切换开关了事"。技术/商业路线判断：OpenAI正从"聊天助手"全面转向"企业级Agent工作平台"，直接对标Anthropic的Claude Code企业化路线和微软M365 Copilot。ChatGPT号称已近10亿用户（工程师Thibault Sottiaux直播称），把Codex能力下沉到这个巨大用户基座是典型的"能力→分发→不可替代"打法。同期背景：OpenAI已秘密递交IPO保密文件，Altman被CNBC问及今年是否上市时回答"我不知道"。

本周（10 月 2 日至 8 日）企业竞争的重心继续从「模型分数」转向「Agent 入口 + 治理/成本 + 资本债务化」，并在三条线上同时展开。

一是 Agent 入口下沉：OpenAI、Google、微软、Meta、NVIDIA、亚马逊云在同一个窗口里把个人/企业 Agent 的落点从云端推到操作系统、PC 设备与企业平台层，竞争焦点变成谁掌握「任务起点与执行环境」，并把它做成可计费、可治理、可植入企业流程的平台。二是价格与治理：Anthropic Claude Haiku 5.5 与 OpenAI GPT-6 Luna 在高并发生产层的价格完全对齐，价格战从前沿旗舰外溢；与此同时，Cohere、Glean、Harvey、Sierra、Cognition 把成本封顶、身份治理、记忆治理做成产品级能力，差异化不再只是「模型多强」。三是资本与算力：中国大模型「上市板块」轮廓成形，海外算力采购从经营性现金转向上游债务驱动。

中国头部大模型企业本周恰逢国庆假期，产品侧多数静默，可入刊动作集中在资本与算力叙事；具身智能则从演示进入量产与估值验证阶段。文中金额、估值与效果类数字凡属厂商自报或媒体/知情人披露者均就近标注口径，融资与估值类未获公司确认。

## Agent 入口下沉到 OS、设备与企业平台

### OpenAI

OpenAI 在 10 月 7 日把新一代 GPT-6 面向全体 ChatGPT 用户推送。据官方博客《GPT-6 and Intelligent UI for everyone》，本次面向其每周 12 亿以上的 ChatGPT 用户（官方口径 >1.2B），并按付费层级分层下发：9to5Mac（10/7）报道，GPT-6 Sol 面向 Plus/Pro/Business/Enterprise，GPT-6 Luna 次日起向 Free/Go 逐步放开。

同一更新引入 Intelligent UI：GPT-6 依问题类型自主组合文本、图表、可点按钮、表单与交互组件作答，官方称配套了原生、可流式的组件库与编译器，界面随模型生成逐步渲染。官方内部评测称，GPT-6 Extra High 可在 GPT-5.6 Medium 的时延内开始作答、总体得分优于 GPT-5.6 Extra High；需要联网搜索时，GPT-6 Instant 平均提前 44% 开始作答。

10 月 5 日，OpenAI 发布 ChatGPT 广告新视觉格式与测量体系：在图片生成中测试新广告位（先面向美国 Free/Go），并接入 Hightouch、Tealium、LiveRamp 及 AppsFlyer、Triple Whale 等归因伙伴。早期伙伴数据显示，WeightWatchers 在 ChatGPT Ads 的归因 CPA 比其付费搜索混合基准低 15.3%。10 月 4—8 日另有欧盟文本溯源方案、与 Atlassian 扩大合作、以“打击 AI 支撑的假前线行动”为题的安全博客等动作。

企业维度上，OpenAI 一手抓前沿模型普惠化与入口扩张，一手抓广告变现：GPT-6 同时进入 ChatGPT 与 API，Intelligent UI 把 ChatGPT 从问答框改造成可产出交互工具/界面的执行层，指向“AI 原生消费平台 + Agent 商业入口”；Intelligent UI 走 Web 与移动端，广告从免费层切入、以测量与归因体系补齐广告主信心。企业侧以 Atlassian 为样板，GPT-6 家族驱动 Rovo 与 Atlassian 平台 Agents，3,000+ Atlassian 开发者使用 Codex（官方）。本周未公开新增融资、估值或高管变动。风险在于：广告进入消费入口带来的隐私与品牌安全争议、Intelligent UI 的实际可用性与时延仅为厂商自评、以及欧盟文本水印监管带来的合规改造成本。

对搭方案者，Intelligent UI 意味着可直接在会话内产出轻量工具与可视化，减少自建 UI 的集成成本，但也提高对厂商入口的依赖；广告与归因体系的搭建说明消费级 AI 流量正在被定价。

### Google（含 DeepMind / Gemini / Google Cloud）

Google Cloud 于 10 月 8 日在「Gemini at Work 2026」发布 Gemini agent，定位为一个“单一通用工作 Agent”：可回答问题、处理知识工作、生成图像与媒体、编写并运行代码，全部从单一 prompt 框完成；它内联进 Gmail/Drive/Docs/Slides/Sheets/Chat/Calendar，具备跨端（Web/iOS/Android/Windows/Mac，CLI/Workspace/Microsoft 365/Slack）常驻记忆与多 Agent 编排，可临时生成带独立身份的 sub-agents，并为公司内部“同事 Agent”分配 @agents.company.com 邮箱与持久存储。

Google Cloud CEO Thomas Kurian 披露：过去一年近 500 家 Google Cloud 客户每家处理超 1 万亿 tokens；近 80% 的 Google Cloud 客户在使用其 AI 产品；近 90% 的财富 100 强使用 Gemini Enterprise。同日，Google Cloud 公布与 Zip US 合作打造“AI 原生产品工厂”的 Gemini Enterprise 案例。10 月 7 日前后 Google 扩展 SynthID Detector 内容识别。DeepMind 侧的 Gemini 4 Argon（9 月）、EmbeddingGemma 2（10 月）等未落入本周窗口，仅作背景。

战略上，Google 把碎片化的 Vertex AI / Agentspace / Code Assist 收敛为「Gemini Enterprise / Gemini agent」单一企业 Agent 入口，走“一个 Agent + 一个 API + Workspace 内生”的开放但强绑定路线；企业渗透数据强，并以行业化（金融、法律）与成本控制（多模型编排、Smart Routing、实时花销上限）为卖点。本周未公开新增融资、估值或高管变动。风险在于：单一通用 Agent 的可靠性与权限治理是落地难点，对 Workspace/Google Cloud 生态的强绑定也可能限制非 Google 客户采用。

对搭方案者，Gemini agent 的“@company.com 同事 Agent + 云端常驻记忆”提供了可参照的企业级 Agent 落地范式，但其开放性与跨云兼容性仍需验证。

### Microsoft（含 Azure / Copilot）

微软在 10 月 7 日的旧金山 Windows and Surface 活动上，把 Windows 重新定位为“AI Agent 最安全的平台”与“混合智能”操作系统。官方同日发布《Building Windows for hybrid intelligence》与《Microsoft Execution Containers: policy-driven containment for AI agents》两篇博客，推出 Microsoft Execution Containers（MXC），为本地 Agent 提供策略驱动的隔离/沙箱；Copilot 更深地内建进 Windows 核心，可在授权下基于本地文件执行操作、本地跑模型并调用云端算力补充；Windows 搜索被改造为类 Copilot 聊天入口（今秋起支持暗色模式、截图、音量、发短信等数千个快捷动作）；并给出“Get Started”工具与 Portable Computer 等首批 Agent。

硬件侧发布 Surface Laptop Ultra，搭载 NVIDIA RTX Spark SoC，NVIDIA CEO 黄仁勋到场与 Nadella 对谈，官方强调“为每家每户、每张桌子带来无限量智能”。微软同时把本地版 MAI-Code-1.1-Flash（编码优化的 MoE，137B 总参 / 6.8B 激活）带到 Windows 与 GitHub Copilot，实现沙箱化本地编码工具。Azure 侧本周以 Partner Center / FabCon Europe 的 AI 辅助运维与存储更新为主。

战略上，微软把“入口之战”从云上 Copilot 延伸到桌面 OS：用 MXC 安全原语加本地模型，抢占“个人 Agent 运行在用户主设备”这一高地，与 Meta Muse、Google Gemini 的桌面对齐；Copilot 从“应用”变为“OS 层”，Windows 搜索聊天化、Agent 开发平民化，Surface Laptop Ultra 加 RTX Spark 打开高端本地 AI PC 硬件位。本周未公开新增融资、估值或高管变动；硬件与芯片合作（NVIDIA/MediaTek/Adobe）体现生态协同。风险在于：本地 Agent 的安全与权限边界（MXC 效果待验证）、Windows Agent 生态相对 Meta Muse 在用户规模上仍在追赶、以及对 NVIDIA 芯片的依赖加深。

对解决方案从业者，MXC 的隔离与策略模型是本地 Agent 交付合规的关键参照，但也意味着深度绑定 Windows 生态。

### Meta AI

Meta 本周的公开动作主要经由 Windows 生态落地：在 10 月 7 日微软 Windows and Surface 活动上，微软宣布 Meta 的 Muse 个人 AI Agent 将以原生应用形式登陆 Windows PC，并采用微软 MXC 沙箱安全机制；据报道 Muse for Windows 尚无发布时间表。作为背景，Muse 是 Meta 9 月 8 日推出的面向所有人的安全私有个人 Agent：运行在自建 Muse Secure VM 云虚拟机上，由 Meta 迄今最强模型 Muse Spark 驱动，可通过 Muse app 或 WhatsApp 对话，能开浏览器、填表、代为议价与下单，并接入 Stripe Link（含 Link 购买保护、一次性卡号隐藏真实卡）与即将支持的 Shop Pay、1Password。（Meta 9 月 29 日的白宫会面同属窗口外背景。）

Meta 在冻结窗内未发布自有前沿模型或重大融资、组织公告，窗口内可核验的实质动态即为 Muse 的 Windows 原生分发落地。战略上，Meta 走消费级个人 Agent 加分发最大化（WhatsApp/Windows 预装）路线，用 Muse Secure VM / Sentinel 双 Agent 架构对冲“把账号与支付交给 Agent”的安全顾虑；Muse 强调零学习成本、为数十亿人构建，与 Windows 原生集成并叠加 Stripe Link 购买保护，是消费 Agent 商业化（代付、交易分成）的关键铺垫。本周未公开新增融资、估值或高管变动。风险在于消费 Agent 的支付与隐私责任、尚无发布日期的 Windows 版本带来的落地时间不确定，以及与 OpenAI/Google 在企业入口的正面竞争尚未体现在本周动作中。

对搭方案者，Muse Secure VM 加支付保护的架构是可复用的高信任消费 Agent 参考范式，但其交易闭环能否形成可持续抽成仍待观察。

### xAI（SpaceXAI）

xAI（现对外品牌 SpaceXAI）在冻结窗内的主要可核验动态是组织与品牌层面：据 Reuters 10 月 4 日报道，SpaceX CEO Elon Musk 于当日发帖称将把公司 AI 部门更名为 SpaceXSI，跟随美国总统 Trump 提出的把“Artificial Intelligence”改称“Super Intelligence”的号召；报道明确指出尚未设定更名日期。除此之外，xAI 在 10 月 2—8 日未发布新的 Grok 模型或重大产品/融资公告——其最新模型 Grok 4.7 于 9 月 21 日发布、Grok Bot for Enterprise 于 9 月 3 日发布，均属背景。官方 x.ai/news 列表、xAI 文档 Release Notes 与主流报道在窗口内均无 xAI 自有重大发布。结论是：本周无重大公开产品/资本动态，仅有更名表态。

战略上，xAI 跟随美国政策话语做品牌对齐，强化与 SpaceX、政府叙事的绑定；窗口内无新品，Grok 系列此前已通过 Microsoft Foundry、Gemini Enterprise、Amazon Bedrock、GitHub Copilot 等第三方渠道分发，显示其走“寄生式渠道”策略。背景口径：xAI 于 2026 年 2 月被 SpaceX 以约 2500 亿美元估值收购，7 月更名 SpaceXAI，8 月收购一家 AI 编程初创；本轮 1 月完成 200 亿美元 E 轮。窗口内无新增融资或高管变动。风险在于核心模型与团队随并入 SpaceX 而组织结构变动、产品节奏与人才稳定性存不确定性，以及在政府部门采用上落后于 OpenAI 等竞对（背景）。本周未见新增重大风险。

对观察者，xAI 本周是“静默 + 品牌表态”的组合，说明其近期重心在并入 SpaceX 后的组织与叙事整合而非产品迭代；其模型分发已高度依赖第三方渠道，值得持续追踪更名后是否影响政府合同与渠道合作。

### Amazon / AWS

AWS 在 10 月 5 日《AWS Weekly Roundup》中回顾 Amazon Bedrock Managed Agents（BMA）的公开预览。该能力由 AWS 与 OpenAI 联合开发，基于定制版 OpenAI Agents API、以 AWS 原生方式运行：可选自托管执行环境或 Bedrock AgentCore Runtime，每个 Agent 拥有独立 IAM 角色，支持高风险动作前的人工审批与 CloudTrail 审计，并可通过 MCP 连接工具。预览期除底层资源消耗外不额外收费，已在 US East（N. Virginia）、US West（Oregon）、US East（Ohio）三个区域开放。同一轮更新还包括在 Bedrock 上引入新的前沿模型、Q3 服务可用性变更与 Kiro 工作流。10 月 7—8 日，AWS 在 IBC 2026 发布四项新的 AWS Elemental 能力，把 AI、个性化与智能变现引入直播视频工作流。

窗口内 AWS 未见重大融资、并购或独立 CapEx 公告，可核验实质为“Bedrock 成为 OpenAI 模型在 AWS 上的托管 Agent 入口”。战略上，AWS 把 Bedrock 从“模型市场”升级为“企业 Agent 运行底座”，以“OpenAI 模型 + AWS 原生治理”的组合把最热模型拉进自家云；BMA 主打身份、权限、审计、审批等企业治理要素，与 Google Gemini agent、微软 Copilot 的企业 Agent 平台正面竞争，无额外费用是快速铺量的策略。本周未公开新增融资、估值或高管变动；背景方面，Amazon 2026 年 CapEx 计划约为 2000 亿美元量级（据 2 月与 7 月报道，非本周数字）。风险在于托管 Agent 的定价可持续性（预览免费、GA 后可能涨价）、企业治理能力能否真正降低落地门槛仍是未知、以及对第三方模型的依赖削弱了自有模型的差异化。

对解决方案从业者，BMA 的 IAM、审批、审计模型是云上 Agent 合规交付的直接抓手；免费预览到 GA 定价的落差，是后续观察其真实采用与成本的关键。

### NVIDIA（含端侧算力与具身投资）

NVIDIA 在 10 月 7—8 日连发两项动作。其一，与微软在旧金山活动联合发布面向“个人 AI Agent 时代”的 Windows PC 方案，核心是 NVIDIA RTX Spark 超级芯片：官方称其为“世界首款专为个人 Agent 打造的 Windows PC”平台，提供最高 1 petaflop AI 算力、最高 128GB 统一内存，集成 Blackwell RTX GPU（6,144 CUDA cores、第五代 Tensor Core/FP4），并通过 NVLink-C2C 连接 20 核 Grace CPU（CPU 由 MediaTek 协同设计）；本地可运行最高 120B 参数 LLM（最高 100 万 token 上下文）、渲染 90GB+ 3D 场景、编辑 12K 视频、生成 4K AI 视频，并运行 NVIDIA OpenShell 与 Windows 新安全原语以安全承载 Agent。Adobe 正为 RTX Spark 重构 Photoshop 与 Premiere（称 AI 与图形性能提升 2 倍）；今秋起 ASUS、Dell、HP、Lenovo、Microsoft Surface、MSI 将推出相关笔记本与台式机，Acer、GIGABYTE 后续跟进（Reuters 10/7 现场确认）。

其二，10 月 8 日 NVIDIA 在华盛顿“Science: A New Golden Age”活动宣布未来五年投入价值 10 亿美元，用于推进美国“超级智能”科研与量子计算、医疗、能源安全，并呼应 Trump 的 Genesis Mission。作为背景（非本周），NVIDIA 于 9 月 28 日授权追加 1500 亿美元股票回购（总额升至 2350 亿美元，为史上最大），同日发布 Open Agent Safety Platform。

具身与物理 AI 生态方面，据 The Information 10 月 7 日报道，NVIDIA 曾考虑、正洽谈向人形机器人公司 Figure AI 投资 10 亿美元（一年前已参与 Figure 超 10 亿美元融资轮），意图把 GPU 从数据中心拓展到家庭场景、让用户本地运行 AI；此消息由 AzerNews 同日转述，未独立核实。Vera Rubin 部署方面，CoreWeave 10 月 7 日公告其孟买 Navi Mumbai 的 240 MW 园区计划部署 NVIDIA Vera Rubin 平台（训练、推理、推理链与 agentic 负载）；背景（非本周），CoreWeave 9 月 30 日已开始向 Cognition 等客户生产级交付 NVIDIA Vera Rubin NVL72。

战略上，NVIDIA 把算力从数据中心延伸到“个人 AI 电脑”，用 RTX Spark 加 OpenShell 抢占端侧 Agent 的芯片与运行时标准，同时以 10 亿美元科研投入绑定美国政府与国家实验室叙事；产品上从 GPU 厂商向“PC SoC + Agent 运行时”扩张，绑定微软、Adobe 与 OEM 生态，把本地 Agent 需求定位为新的算力增长曲线。本窗口无新增融资或高管变动；强烈资本信号来自 9 月 28 日的 1500 亿美元回购与 Q2 FY2027 创纪录的 962 亿美元营收（据 WSJ，均属背景），本周资本信号为 10 月 8 日的 10 亿美元科研承诺。风险在于：端侧 1 petaflop 的实际能效、散热与软件生态成熟度待验证，科研投入回报周期长，美国政策绑定带来地缘与出口管制敞口。

对搭方案者，端侧 1 petaflop 加 128GB 统一内存使“本地跑大模型/多 Agent”首次具备硬件基础，但 OpenShell 与 MXC 的沙箱能力及生态工具成熟度仍是落地前提；10 亿美元科研承诺是资本向政策、科研侧延伸的信号。

## 价格战外溢到高并发生产层

### Anthropic

Anthropic 于 10 月 7 日发布 Claude Haiku 5.5，官方定位为“迄今最快、最便宜、最强的小模型”，面向高并发、成本敏感的任务。据 VentureBeat 读取的发布材料，其短请求（低于 10 万 tokens）定价为每百万输入 token 0.10 美元、每百万输出 token 0.50 美元，较 Haiku 4.5 降价约 90%；超过 10 万 tokens 时升至 0.50/2.50 美元（降 50%）。Anthropic 称约 90% 的 Haiku 4.5 请求属短请求，综合 tokenizer 变化后典型负载成本约降 75%。厂商自报的 benchmark 为：OSWorld 2.1 计算机操作由 Haiku 4.5 的 15.7% 跃升至 72.4%，Terminal-Bench 4.0 的 agent 编程由 0.0% 升至 39.2%（均为厂商口径、未独立验证）。

同期，Anthropic 在 SF Tech Week 宣布扩大 Claude for Startups（TechCrunch 10/6）：符合条件（近 5 年成立或近 2 年融资）的初创可获 1 年免费 Claude Team（最多 5 个高级席位）、1,000 美元 API credits 与 Claude Marketplace 插件访问权。10 月 8 日，Anthropic 发布《2026 使用政策更新》：新增“禁止欺骗性宣传与虚假活动”章节，聚焦影响行动、武器开发与监控滥用，并澄清健康、金融高风险用例及 Claude 自主执行物理动作的控制，政策 11 月 12 日生效。

战略上，Anthropic 以“价格战 + 入门小模型 + 初创生态”争夺高并发生产工作负载的默认入口，把小模型定位为 Opus/Sonnet 的“支撑工人”而非替代。Haiku 5.5 与 OpenAI GPT-6 Luna 在短请求四档价格完全对齐，形成正面价格对攻；同期 Anthropic 下调了 Sonnet 5.5 缓存费、给 Max/Team 订阅者月度 API credits，创业补贴则直接抢占 Builder 心智。本周未公开新增融资或估值，政策与合规团队持续输出监管文档。风险在于：厂商自报 benchmark 未独立复核；Haiku 5.5 在长上下文的实际 token 消耗增加，降价的实际净值取决于工作负载；政策收紧可能影响部分高风险行业客户。

对解决方案从业者，短请求单价跳水意味着文档处理、分类、检索类 Agent 的单位成本显著下降，可作为多 Agent 架构里“廉价执行层”的选型依据；初创补贴说明头部厂商正用免费额度争夺开发者分发。

## 治理、成本与记忆：企业 Agent 的新卖点

### Cohere

Cohere 本周三线并进，并首次给出“合并后公司”的完整叙事。10 月 5 日，它发布 North 2（称 North 史上最大升级）：把企业级安全、智能、成本治理与全栈控制统一到单一 agentic 平台，核心升级包括可跨组织共享的可复用 agent 与自动化、跨会话记忆、Skills/Libraries、从自然语言原型化并交付 deck/仪表盘/文档/轻应用、拖拽式工作流构建器与实时监控，并新增 Slack、SharePoint、OneDrive、Outlook、Exchange、Jira、Linear、Notion、GitHub 连接器（计划接入 PitchBook、Crunchbase、S&P Global、FactSet 等金融数据源）。North Admin 提供按用户/agent 的 token 花费追踪、角色权限、用量配额、速率限制、组织级封顶与阈值告警；平台模型无关，可跑 Cohere 模型或自带模型。官方称与 NVIDIA 合作，在 Blackwell/Hopper 上提升每节点每秒 token 数、降低花费。

同日，Cohere 与 PwC 宣布全球联盟（从加拿大起步）：Cohere 提供安全 AI 基座（North、企业模型与搜索检索），PwC 负责用例识别、风险与合规评估、流程再造、治理与集成落地，直指受监管行业的数据主权与合规要求。相关报道还复述了 Cohere 与德国 Aleph Alpha 的合并进展：双方于 9 月 16 日签署最终业务合并协议（4 月 24 日首次宣布），合并后仍以 Cohere 运营、双总部柏林与多伦多、海德堡聚焦研究；Aidan Gomez 任 CEO，Ilhan Scheer 加入任 COO、Samuel Weinbach 任 CRO；合并估值约 200 亿美元，仍待监管批准，Schwarz Group 承诺向 Cohere 即将到来的 Series E 投资约 5 亿至 6 亿美元。

战略上，Cohere 走“主权 AI + 私有化部署 + 企业 agent 平台”路线，明确不做消费级聊天与 AGI 竞赛；North 2 把“安全、智能、成本、控制”四难变四全，PwC 联盟补交付与合规能力。token 花费治理直击企业财务对 agent 成本失控的恐惧，模型无关加连接器扩张使其可被当作企业 agent 的“harness 层”——官方称相当比例营收来自 harness（Pineau 语，转述）；客户含 LG CNS（韩）、RBC、Dell、stc、Ensemble Health Partners 等。本周无新轮关闭；背景口径为 2025 年末确认估值 70 亿美元，2026 年 9 月彭博报道其洽谈 20 亿至 30 亿美元、估值 200 亿美元。风险在于：合并仍待监管批准（跨大西洋交易不确定性）；200 亿美元估值对应的营收口径（如 2025 年 ARR 2.4 亿美元、约 70% 毛利、85% 营收来自私有部署）来自披露与报道、未经独立审计；私有化与气隙部署的重交付成本；North 2 效果为公司自述。

对做企业 agent 方案者，North 2 的按 agent token 封顶与模型无关 harness 是可直接对标的设计；对采购方，200 亿美元估值与合并的不确定性意味着合同需含价格保护与退出条款。

### Glean

Glean 本周以连接器与 MCP 生态扩张、模型与治理能力升级为主。10 月 6 日发布 Release 560：GPT-6.1 Sol 在支持的 Glean 体验中上线（可用性取决于部署的模型 Key 方案，Glean Universal Model Key 由 Glean 管理访问，客户自带 Key 则需自备 OpenAI 凭据）；Showpad 连接器转为正式可用；Vitally 连接器开放 beta；Assistant 模型选择器重构，新增成本与智能评级及“各模型擅长什么”说明；浏览器扩展改在浏览器原生侧栏打开；并做安全加固（Agent Builder 的 prompt 增强更抗恶意指令注入），子代理可接收全部 AI 生成输入。

更早的 10 月 1 日版本新增 6 个远程 MCP 服务器模板（GIS Cloud、Lightrun、MYOB、PaidSync、Avoma、Prisma Postgres，多为 per-user OAuth），并宣布 Agent Identity 正式可用（给 agent 独立受治理账号、scoped 凭据与审计轨迹）；报道统计 Glean 在 9 天内四个版本共新增 280 个 MCP 模板（9/22 +182、9/24 +25、9/29 +67、10/1 +6）。10 月 4 日报道称，Glean 以 Enterprise Context 为“工作 AI 地基”，用 275+ 连接器构建 Enterprise Graph，并通过 Glean MCP 把受治理上下文喂给 Claude Code、Codex、Gemini、Cursor、Copilot，配 AI gateway、模型 hub、用量控制与 agent 治理。10 月 8 日，印度软件公司 Evon Technologies 宣布成为 Glean 的经销商/实施方并提供 24×7 支持。

战略上，Glean 明确从“企业搜索”转向“公司上下文 + 治理的 Enterprise Context 平台”，把自身定位为多家前沿 agent 底下的“地面层”（grounding、权限与 MCP 网关），不与被集成模型正面竞争；靠连接器与 MCP 模板的规模化构建“数据接入面”护城河，Agent Identity、AI gateway 与用量治理回应企业最担心的权限与成本两大问题，模型选择器则把“成本与智能”的权衡交给用户。本周未公开新增融资；背景口径为 2026 年 5 月宣布 ARR 超 3 亿美元、8 月有 7.68 亿美元增长轮报道、2025 年 6 月完成 1.5 亿美元 F 轮、估值 72 亿美元。风险在于：MCP 模板数量的爆发带来治理与安全面扩大（工具投毒、rug-pull 风险），permissions-aware 索引若源系统权限本身配置错误会产生快速泄漏，模型选择器与 Deep Research 的计费口径变化需向客户明确。

对搭企业 agent 的团队，Glean MCP 提供了把公司数据受治理地接入 Claude Code、Cursor、Copilot 的现实路径；但 MCP 模板的高速扩张与企业级安全治理的平衡，是选型时必须验证的点。

### Harvey

Harvey 本周以“客户落地 + 与 LexisNexis 的联合工作流 + 安全基建”三条线推进。其一，10 月 5 日宣布北美最大能源基建公司之一的 TC Energy 在其法务团队全面部署 Harvey，支持跨加拿大、美国、墨西哥的复杂法律工作；试点期引入“Harvey-First”指令（律师先用 Harvey 走一遍），覆盖诉讼、监管、公司交易与并购、商业合同、合规，该关系也深化了 Harvey 在加拿大的存在（多伦多办公室与本地团队扩张）。

其二，10 月 7 日推出与 LexisNexis 联合开发的首个工作流——Motion to Dismiss（MTD）起草代理：四阶段 review-and-approve 流程中，规划代理读取起诉状并按强度排序最多 8 个驳回理由，律师批准或调整后，并行研究代理用 LexisNexis 美国法源检索、经 Shepard's 校验并标注 Signal，最后由起草代理产出含 TOC/TOA、符合特定法院程序（加州 demurrer、纽约 CPLR 3211、宾州初步异议、联邦 Rule 12(b)(6)）的成稿；官方称把原本 40 至 50 小时以上的助理工作压缩到数小时。该工作流向有 Ask LexisNexis 或 Lexis+ Protégé 的客户开放，下一步是 Motion for Summary Judgment。

其三，同日发布 MCP Policy Engine：为 MCP 工具接入提供运行时控制（最小权限、工具动作全中介、信息流控制），含 Tool Pinner（追踪已批准工具的后改动，防“rug-pull”）与 Sanitizer（清除工具结果中的隐藏字符与恶意指令），直指提示注入与工具投毒；公司称其服务 3,000+ 客户、覆盖 70+ 国家。10 月 7 日另有报道详述新一代 Harvey ii（用户级记忆并以“案件”组织 spaces）及加拿大数据驻留安排：客户可选把数据存于加拿大的微软数据中心，但推理需出境、经 OpenAI 在美国、欧盟、澳洲处理。

战略上，Harvey 以“与 LexisNexis 等权威法源深度绑定 + 大客户法务整体部署”构建法律垂直护城河，同时把 agent 安全与治理做成产品级能力，抢占企业级 agent 信任位；产品上从“让律师用 AI”走向“用 agent 替代整段高耗时文书流程”，客户结构向大型跨境企业、能源与金融延伸，数据驻留与合规能力是进入受监管行业的关键卖点。本周无新增融资；背景口径为 9 月 9 日完成 5.5 亿美元融资、估值 155 亿美元（由 Diffusion 与 Lightspeed 联合领投），此前另有 2 亿美元、估值 110 亿美元等窗口外轮次。风险在于：MTD 属高风险法律产出，官方明示律师须逐段复核、存在幻觉与错误风险；加拿大推理出境带来跨境合规与数据主权的持续张力；与 LexisNexis 的深度绑定既是壁垒也是依赖。

对搭企业 agent 的公司，Harvey 的 MCP Policy Engine 思路（工具固定与结果净化）提供了可直接借鉴的生产级安全范式。

### Sierra

Sierra 本周密集发布，是年度峰会后的产品与生态高密度周。10 月 6 日的峰会回顾（署名 Bret Taylor、Clay Bavor）发布 Agent OS 两项新模型：Curie 负责对话核心编排回路（决定路径、调用工具、撰写回复），Fleming 用于识别来电方是否为另一个 AI agent（应对机器人、欺诈与个人 agent）；同时发布 Tandem Voice（会话层实时响应加推理层慢思考的“快慢双轨”）与 Persona Studio（上传自有声音样本、无需工程即可调人格），并预告重构版 Ghostwriter（持续监控 agent、主动发现改进点的“常驻队友”）。官方披露客户已覆盖约一半的 Fortune 50、三分之一的头部银行、80% 的 Fortune 50 医疗公司。

同日，Sierra 发布合作伙伴生态（技术平台、marketplace、服务伙伴），宣布上架主流云与前沿实验室 marketplace、可用既有云承诺采购；并与 Meta 及 Genesys、Instinct、Rocket、Shopify、Stripe、Walmart 等行业伙伴共同制定开放标准 Personal Agent Protocol（PAP），定义个人 agent 如何与企业交互（认证、可开放的功能边界），同步上线 Stripe App Marketplace（agent 可在对话中安全收集支付信息直送 Stripe）；Fleming-1 于 10 月 7 日落地，任何基于 Sierra 的语音 agent“打开即用”。

10 月 7 日的客户案例披露，菲律宾航空（PAL）用 Sierra 加 ibex 部署三语（英语、他加禄语、Taglish）语音 agent：2026 年 4 月上线 3 条热线，后扩至美国线路（增约 7 万通话/月），900+ FAQ 场景准确率 98% 以上，CSAT 4.7/5，并通过改写一条会员层级问题把误转人工率从 15.5% 降到 7.2%。

战略上，Sierra 以“结果计费（按解决量付费）+ Agent OS 平台”切入企业客服与营收场景，用 PAP 开放标准与 marketplace 上架抢渠道与生态位，把“关系与上下文归客户所有”作为对抗同质化模型的主张；产品从客服向长周期目标、语音与多语种、支付闭环扩展，客户含 Rocket Mortgage、SiriusXM、Vanguard、Wayfair、GAP、SoFi、Sutter Health、SoftBank、Singtel、Cigna、Nordstrom 等。本周无新增融资；背景口径为 2026 年 5 月完成 9.5 亿美元融资、post-money 估值 158 亿美元（Tiger Global 与 GV 领投），2026 年 2 月 ARR 超 1.5 亿美元、5 月据 Sacra 估达 2 亿美元。风险在于：结果计费的“解决率”口径与真实满意度可能背离、需防刷单；PAP 为早期开放标准，部分 agent 可能不遵守、认证与防伪仍待落地；语音 agent 的多语种准确率、误转率与幻觉在银行、医疗等受监管行业容错极低。

对做客服与营收 agent 方案者，PAP 与 Stripe、marketplace 上架意味着可复用的集成与采购路径，但需自建防刷与防伪造来电的治理层；对 CX 负责人，多语种语音 agent 已具备替代部分外包坐席的可验证案例。

### Cognition

Cognition 本周发布 Devin 的跨会话记忆与“做梦”机制。10 月 5 日公司博客（“Memory and dreaming: how Devin learns from working with you”）宣布两项能力：Memory 让 Devin 跨会话记住用户偏好、纠正与项目经验；Dreaming 是每日异步后台进程，重新审视历史对话与既有记忆，合并重复、剪除临时或长期未用信息、解决矛盾、补录此前未记录的经验。实现上，记忆存于个人 Memory Drive（持久化 Git 仓库、以 Markdown 组织、以 MEMORY.md 为入口索引，每会话独立 Git checkout、结束提交合并、用 Git 版本检查防陈旧写入）。Cognition 同时把该方案开源为独立标准 Agent Memory Repo（MIT），其他 agent（Claude Code、Cursor 等）可用同法把长期记忆存成文件并以 Git 管理，但“像 Devin 一样每日自动 Dreaming”仍需自行额外配置。需要注意的是，Cognition 未公布任何 benchmark、用户研究或“减少重复纠正/提速”的量化结果，也未说明错误记忆如何被编辑或标记。

战略上，Cognition 从“单个自治 agent”转向“agent 平台 + 记忆基础设施”，并把记忆方案开源成标准，以争夺 agent 生态的“记忆层”话语权；产品面由 Devin、Devin Desktop（原 Windsurf）、Devin CLI、Devin Review 与 DeepWiki 构成。Memory 与 Dreaming 直击 agent 长期上下文丢失这一核心可用性痛点，也是企业团队知识沉淀的卖点，但官方无效果量化，属“机制先行、效果量化本次未取得”；SWE-2（9 月 11 日发布，窗口外）在 Devin Desktop 与 CLI 免费促销至 10 月中。本周无新增融资；背景口径为 2026 年 5 月逾 10 亿美元、post-money 260 亿美元，9 月 10 日 Series E 逾 20 亿美元、估值 480 亿美元（a16z 与 Accel 领投），9 月 25 日年化营收据报破 10 亿美元。风险在于：记忆正确性治理缺失，错误记忆可能被反复使用且存活性清理无法识别真伪；Dreaming 的自动改写记忆若缺乏审计与可编辑性，在合规场景有风险；公司自报营收与估值口径未经审计；Devin 在长任务与 flaky 测试下的成本不可预测（ACU 计费）。

对搭 agent 的团队，Agent Memory Repo 的“Git + Markdown 记忆”范式可低成本复刻到自有 agent；但“错误记忆如何被纠正”这一未被回答的问题，是企业规模化前必须自建治理的核心缺口。

## 中国大模型：资本与算力叙事，产品侧假期静默

### 华为 / 昇腾 / 盘古

华为本周（窗口内集中报道）围绕昇腾算力释放出一组强信号。2026 年 10 月 3 日起，多家媒体转发华为轮值董事长徐直军在 2026 华为全联接大会（HC2026，9 月 17 日举行，属背景）期间媒体问答的要点：徐直军称“目前很难收集英伟达在中国市场份额的数据，但根据华为收集的数据，昇腾已经超越英伟达”，并披露昇腾 950 系列节奏——先上市面向 AI 推理的 950PR，基于昇腾 950DT 的 Atlas 950 SuperPoD 面向 AI 训练、当前处于测试中，大规模供应将在“今年年底或明年年初”开始；他还提到华为因产能不足以满足国内需求，没有计划全面拓展国际市场，仅向少数强需求国家有限供货。

新浪财经同步刊出问答全文（10 月 5 日），披露 Atlas 950 SuperPoD 基于华为自研 Peerium 计算架构（嵌套 BSP + 统一内存寻址 + 对等互连，目标百万处理器像一台计算机），配套自研 UnifiedBus（灵衢总线）以单一协议同时支持纵向与横向扩展，机架间带宽最高 800 GB/s；搭载 384 颗 910C 的 SuperPoD 已出货 1000 多套，25.6 万卡规模的 SuperCluster 正在部署测试。海思首席科学家廖恒称，中国未来两年约 6 至 7 家前沿实验室将训练 10 万亿至 40 万亿参数模型，20 万卡级集群是匹配需求的下限规模。本周动作的实质是：华为把“国产算力自给 + 超节点规模优势 + 份额超越”作为对外叙事主线集中输出（原始事件在 9 月大会，本周为报道与再披露）。

战略上，华为以“芯片—总线—超节点—集群”全栈自研锁定国产 AI 算力底座，把供应能力（而非销售推力）作为扩张约束条件，优先保障国内训练集群；昇腾 950PR（推理）已上市但总量有限、950DT 超节点（训练）年底或明年初放量，UnifiedBus 单一协议方案对标英伟达 NVLink + InfiniBand 双协议，主打机架间高带宽与低转换开销。对搭方案者，国产训练与推理底座的可选性与供应链确定性上升，但当前供给偏紧、拿货节奏仍是瓶颈。本周无新增融资或上市披露。风险在于：徐直军“昇腾份额超英伟达”为华为单方口径、未独立复核，不宜作为市场权威统计；先进制程产能受限、950DT 放量时点存在执行风险；高端光模块（Hi-ONE，NPO 7.2T）量产与供应链是另一约束。

对做解决方案者，国产训练底座从“可用”走向“规模化可交付”是重要转折，但需以实际供货与集群实测为准，而非仅凭管理层口径。

若该轮完成，将成为中国 AI 单轮融资新极值，直接为 2027 年 IPO 与算力、人才扩张备弹，并强化“低成本旗舰模型”对全行业定价的压制；其开源权重加低价 API 继续是成本敏感场景的首选底座，也是一级市场对“能力性价比”重新定价的强信号。

### 阿里 / Qwen / 夸克

2026 年 10 月 2 日，阿里云“百炼”大模型服务平台上线 Qwen-Image-2.1-Pro（模型 ID qwen-image-2.1-pro），定位为统一的文生图与图像编辑模型，其视觉生成组件仅含 70 亿参数（32 层单流 DiT）。据阿里云官方文档，该版本含四项关键改进：紧凑高效（轻量级架构、混合粒度注意力机制与前缀 KV 缓存复用，在低计算开销下实现高质量生成）；原生透明支持（可从文本生成普通或透明 RGBA 图像、编辑透明图层并从照片中提取主体，全部由单一模型完成）；多功能编辑（支持最多 10 张参考图像，可通过圆形、手绘标注或独立蒙版指定局部编辑区域，并保留人物与产品身份特征）；改进字体排印、人像光照与细节表现。

作为背景（非本周），Qwen-Image-2.1 的开源版此前于 9 月 24 日前后发布，阿里当时称其在图像能力上对标并“击败”Google 的 Nano Banana 2.0，本周动作是把该能力以托管 API 形式落到百炼商业化通道；9 月 28 日还有报道称千问 App 已与夸克网盘打通，可调用 Agent 技能实现资料查找、照片海报创作与自动上传分享。C 端（千问 App、夸克）与 B 端（百炼）双线本周均无新的分发或补贴级动作披露。

战略上，阿里维持“模型能力持续迭代 + 通过百炼做 API 商业化”的双轮，把开源版当作生态入口、托管版当作收入与合规通道；Qwen-Image-2.1-Pro 补齐了百炼在图像生成与编辑的旗舰位（此前为 6 月 22 日上线的 Qwen-Image-2.0-Pro），面向电商素材、营销海报、透明图层设计等可付费场景。对搭方案者，文生图与图像编辑可直接走百炼托管，省去自建推理与 RGBA 处理链路，集成门槛降低。本周无新增公开融资、组织或人事披露；定价与调用量“本次未取得”。风险在于图像生成赛道竞争激烈（Google Nano Banana 系列、字节 Seedream 等）、价格与效果持续被拉平，以及托管版定价与开源授权条款（有媒体质疑其许可限制）仍是采用方的顾虑点。

这是一次常规但有信号意义的“能力—通道”落地：阿里把前沿图像能力从开源引流转向百炼托管变现，说明其 2026 下半年商业化优先级继续高于纯刷榜；下一步看百炼侧的定价与真实调用量是否公开。

## 算力与资本：债务驱动与供给前置

本周算力侧的核心矛盾是“供给与融资”：一方面 AMD 抢 2027 年产能、CoreWeave 锁定印度电力与最新芯片代际；另一方面 Broadcom 为 OpenAI 定制芯片筹组逾 500 亿美元债务融资、Oracle 亦寻求芯片融资。AI 算力正从经营性现金采购转向绑定大客户加债务驱动，Broadcom、CoreWeave、Oracle 的订单与财务风险同步放大。

### AMD

AMD CEO 苏姿丰 10 月 6 日在台北对记者表示，AMD 计划在 2027 年“大幅增加”芯片供应以应对 AI 需求；她说“我们在 2026 年全年一直在提升供应能力，2027 年将大幅增加”，并指出公司需要更多先进晶圆产能来满足预计会持续数年的需求。同期她在台北会见了富士康、台积电等供应链伙伴，随后将前往韩国（三星、SK 海力士所在地）与存储芯片厂洽谈，以保障 HBM 与内存供给。10 月 6 日，AMD 公告将于 11 月 3 日盘后发布 2026 财年第三季度财报，并公布 12 月两场投资者活动（UBS 12 月 1 日、Barclays 12 月 9 日）。市场层面，10 月 6 日 AMD 股价创历史新高（同日英伟达亦创历史新高，市值逼近 5.8 万亿美元）。作为背景（非本周），AMD 此前已公布 OpenAI 6GW、Meta 6GW、Anthropic 2GW 等 MI450/Helios 部署承诺，并发出最多 3.2 亿股（每方 1.6 亿股、行权价 0.01 美元）认股权证绑定采购里程碑。

战略上，AMD 从“卖芯片”转向“锁定上游产能加绑定大客户股权”的双向绑定，供给成为 2027 年的竞争胜负手，苏姿丰亲赴台、韩谈产能与 HBM 供应即是信号。Instinct MI450/Helios 机架与第六代 EPYC（Venice）是主要增长引擎；管理层将 CPU 市场 TAM 上修至 2030 年超 2000 亿美元、目标份额超 50%（背景）。本周无新品发布，也无新增融资或高管变动，关注点是 11 月 3 日的 Q3 财报。风险在于：内存、HBM 与先进制程产能受限可能拖累交付；客户端集中度高（OpenAI、Meta、Anthropic），股权与采购绑定的会计与现金流复杂度上升；与英伟达、各厂自研 XPU 的三线竞争挤压。

对搭方案者，2026 下半年到 2027 年的 MI450 供给量与定价仍取决于内存和先进封装，企业采购不应假定“供给充足即价格下行”；11 月 3 日财报是验证数据中心收入与毛利率的关键节点。

### Broadcom

## 应用与垂直头部：平台化、开放权重与新计费

本周应用与垂直头部的动作高度收敛到同一方向：把单点产品扩成“agent 平台 + 上下文/记忆/工具底座”，竞争焦点从“模型能力”转向编排、记忆、工具接入与企业可用性；治理、安全、成本控制成为新的差异化维度，开源权重与开放标准则成为新兴公司的通用分发武器。

### Runway

Runway 在 9 月 30 日于旧金山 Masonic 举办为期一天的 AI Summit，窗口内（10 月 2 至 3 日）多条报道披露其发布内容，本周是其战略重心从“创作工具”向“世界模型、物理 AI、营销自动化”扩张的高密度周。核心事件是发布 Praxis-1：公司称其为首个开放权重的“world action model”，建立在其通用世界模型的大规模视频预训练之上，把视频预训练转为机器人控制策略；官方称在自家世界模型中仿真机器人策略、与真机结果相关性达 0.95，且策略性能随第三人称视频规模增长，即瓶颈是“可得的视频数据”而非稀缺的遥操作机器人数据。早期伙伴 Noble Machines、Standard Bots、Ultra 已在自有硬件（从双臂到人形）上轻量微调运行，公开发布时将以 open weights 而非闭源交付，计划“数月内”面世。同周推出的 Runway Ads 定位自主绩效营销引擎，可生成并跨 Meta/Google/TikTok 发布与跟踪广告，官方与媒体报道称转化率提升 34%、CTR 持稳、广告投放量扩 1000%，付费约每月 12 美元起。峰会上 Runway Labs 还展示了 Continuum（自称实时视频操作系统）及 Interface World Models 家族首个模型 Solaris（逐帧生成界面、无中间代码表示），但公司未公布 Continuum 的访问与技术细节。

## 具身智能：从演示到量产与估值验证

具身智能本周从“演示”进入“量产与估值验证”：Tesla Optimus 目标 2026 年底千台每周、Figure 世代切换、优必选万台工厂交付对比宇树股价腰斩——本体量产能力与资本定价出现明显背离，市场开始惩罚高估值、奖励真实交付与回款。

### Tesla Optimus

本周 Tesla Optimus 的核心信号是量产爬坡目标与产能切换。据 10 月 8 日报道，Tesla 计划在 2026 年底前把 Optimus 周产量提升到 1,000 台以上，较 2026 年第二季度约 10 倍增长（相关报道引述 The Information 独家）。为腾出产能，Tesla 已把 Model S 与 Model X 的生产区域在 46 天内改造为机器人产线。同时有媒体指出，Optimus 的手部与前臂制造仍是瓶颈：需要大量手工装配，部分手部自动化装配站的精度与一致性不足，拖慢放大节奏。Musk 曾称 Optimus 3 目标在 2026 年夏启动 S 型爬坡，并预计公众可在 2027 年底买到 Optimus；2024 年他给出的价格预期为 2 万至 3 万美元，而部分分析师认为实际上市价可能在 5 万至 10 万美元。需要说明的是，Tesla 从未公布 Optimus 实际产量数字，此前可信报道称累计建造量为低三位数。

战略上，Tesla 把汽车产线改为机器人产线，押注 Optimus 为“史上最大产品发布”，以制造规模化作为竞争壁垒；Optimus 定位工厂内自用加未来对外销售，目前无住宅或商业预售渠道，也未公布官方售价与上市日期；本周无新增融资，产能与人力从汽车业务倾斜至机器人。风险在于：手部与前臂装配良率及自动化一致性是明确工程瓶颈；产量目标属管理层预期而非已实现；Musk 交付历史多次跳票；商业化时间表（2027 年底）不确定。

Optimus 从“演示”走向“产能切换”，但手部装配瓶颈说明人形机器人量产仍是制造问题而非算法问题——对供应链（灵巧手、执行器、减速器）从业者意味着高价值环节在手与前臂；周产量目标是关键观察锚。

Figure 本周有两条新闻。其一，Figure 02 整机队退役：Figure 把大部分 Figure 02 人形机器人送往芬兰 Imatra 的钢厂，让它们在熔融钢水（75 吨电弧炉）中完成“最后一跳”进行拆解，公司称该方法可保护专有硬件、避免逐台拆机，少量 Figure 02 仍封存。这标志着 Figure 02 时代结束（其曾在宝马 Spartanburg 工厂处理 9 万以上零件、参与 3 万以上车辆），产线转向 Figure 03。其二，据 The Information 10 月 7 至 8 日报道，Nvidia 曾考虑向 Figure AI 投资 10 亿美元（一年前已参与 Figure 超 10 亿美元融资轮），意图把 GPU 从数据中心拓展到家庭场景、让用户本地运行 AI。作为背景（非本周），Figure 于 9 月 17 日发布 Helix 2.5 通用化模型（30 个未见住宅零样本家务成功率 56%，对比基线 8%），并承诺初期 35 亿美元、最多超 60 亿美元的 AI 基础设施投入，与 Nscale 合作最多 10 万块 NVIDIA GPU（2027 下半年部署）。

战略上，Figure 以 Helix 通用化模型、Index 人类行为数据集加上大规模算力与数据投入构建“机器人基础模型”护城河，并快速迭代本体（02→03→04）；Figure 03 面向家庭（173cm、61kg、负载 20kg、5 小时续航），Figure 02 曾用于宝马产线，公司处于从工业走向家庭的过渡期。Nvidia 的潜在 10 亿美元新投资由 The Information 报道、未独立核实；此前 C 轮超 10 亿美元、估值约 390 亿美元。风险在于：零样本成功率（56%）距实用仍有差距；家庭场景商业化与成本未验证；对 Nvidia 算力与资本的依赖度上升。

对从业者，Figure 用“熔钢退役”完成世代切换，若拿到 Nvidia 第二笔大额投资，等于把“物理 AI 入口”进一步绑定 GPU 生态——人形机器人竞争正从硬件转向“基础模型加数据加算力”的重资本赛道。

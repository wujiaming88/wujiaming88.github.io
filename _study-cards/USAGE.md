# 使用指南

## 快速开始

访问 https://wujiaming88.github.io/study-cards.html

## 学习流程

### 1. 查看卡片
- 卡片正面显示问题
- 左上角圆点表示卡片优先级:
  - 🔴 红色 = 必考/高频
  - 🟡 黄色 = 中频/重点
  - 🟢 绿色 = 低频/了解
- 右上角显示章节名称

### 2. 翻转查看答案
- 点击卡片任意位置翻转
- 背面显示完整答案
- 表格内容会自动格式化

### 3. 评分记忆效果
根据回忆难度选择:

| 按钮 | 含义 | 下次复习 |
|-----|------|---------|
| 忘了 | 完全不记得 | 1 分钟后 |
| 困难 | 勉强想起来 | 今天内再复习 |
| 良好 | 能想起来但费力 | N 天后 (算法计算) |
| 简单 | 轻松回忆 | 间隔 × 2.5 |

### 4. 筛选学习内容
点击右下角 ⚙️ 按钮打开筛选面板:

**颜色筛选**:
- 全部: 220 张卡片
- 只学红卡: 106 张必考题
- 只学黄卡: 89 张重点题
- 只学绿卡: 25 张了解题

**章节筛选**:
- 28 个章节可选
- 可单独学习某一章节
- 适合临考前突破薄弱章节

## 统计面板

顶部显示 4 项统计:

| 指标 | 说明 |
|-----|------|
| 今日 | 今天已复习的卡片数 |
| 待复习 | 到期需要复习的卡片数 |
| 新卡 | 尚未学习的卡片数 |
| 已掌握 | 掌握率 (间隔 ≥ 21 天的比例) |

进度条显示今日学习进度。

## 学习建议

### 首次使用
1. 先学红卡 (106 张),保证必考点掌握
2. 每天新卡限制 20 张,避免负担过重
3. 坚持每日复习到期卡片

### 冲刺阶段
1. 全部卡片都过一遍
2. 重点复习"困难"标记的卡片
3. 红卡保持每天都复习

### 考前一周
1. 只复习红卡和黄卡
2. 确保掌握率 > 80%
3. 绿卡可以放弃 (分数不高)

## 间隔重复原理

基于 SuperMemo SM-2 算法:

```
第1次评分≥3 → 1天后复习
第2次评分≥3 → 6天后复习
第3次及以后 → 间隔 × 容易度因子
```

容易度因子根据评分动态调整:
- 评分 5 (简单) → 因子增加
- 评分 3 (困难) → 因子减少
- 评分 < 3 (忘了) → 重新开始

## 数据管理

### 查看学习数据
打开浏览器开发者工具 (F12):
```javascript
localStorage.getItem('study-cards-state')
```

### 导出数据
```javascript
// 复制到剪贴板
copy(localStorage.getItem('study-cards-state'))
```

### 导入数据
```javascript
localStorage.setItem('study-cards-state', '粘贴数据')
location.reload()
```

### 清除所有进度
```javascript
localStorage.removeItem('study-cards-state')
location.reload()
```

## 常见问题

### Q: 为什么刷新后进度丢失?
A: 检查浏览器是否启用了"无痕模式"或"阻止 Cookie",需要允许 localStorage。

### Q: 能否在多个设备同步进度?
A: 不能自动同步。可手动导出/导入数据 (见上方"数据管理")。

### Q: 卡片顺序是否随机?
A: 不是。队列按到期时间排序,越早到期越靠前,新卡排在最后。

### Q: 能否调整每日新卡数量?
A: 目前固定 20 张/天。如需修改,需要重新构建 HTML (修改源码)。

### Q: "忘了"和"困难"有什么区别?
A: 
- **忘了**: 重置进度,从头开始,1 分钟后复习
- **困难**: 不重置进度,今天内再复习一次,间隔仍会增长

### Q: 为什么有些卡片间隔很长?
A: 这是正常的。SM-2 算法的核心是拉长间隔,减少复习次数。如果你持续评分 4-5,间隔会达到几个月。

### Q: 能否添加自己的卡片?
A: 目前不支持在线添加。需要修改 `cards-data.json` 并重新构建。

## 技术细节

- **算法**: SuperMemo SM-2
- **存储**: localStorage (浏览器本地)
- **依赖**: 无 (纯静态 HTML)
- **兼容**: Chrome/Safari/Firefox (现代浏览器)
- **文件大小**: 95 KB
